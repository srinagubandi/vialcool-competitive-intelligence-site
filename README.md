# VialCool U.S. Competitive Intelligence Site

A standalone executive research site for VialCool’s U.S. portable medication-cooling category. It combines competitive landscape research, public Google/Meta ad-transparency evidence, keyword and bid architecture, channel and audience recommendations, compliance guardrails, creative concepts, and a 30/60/90-day execution plan.

## Publish

The site is published as a static GitHub Pages site from the `site/release-1.0` branch. Open `index.html` locally for an offline copy.

## Evidence boundary

Public ad libraries document visible advertiser presence, creative, copy, dates, and library IDs. They do not establish competitor spend, reach, CPC, CAC, conversion, or ROAS. TikTok’s public ad-library query returned a blank/JavaScript-only view in the research session and is identified as an evidence gap in the site.

## Model method

The integrated strategy was editorially synthesized with Qwen3 235B A22B Thinking through OpenRouter from the completed competitive research, paid-growth synthesis, ad-intelligence synthesis, and public evidence pack.
